# Animated HTML Components Skill

This skill creates reusable, animated HTML components and interactive UI elements. Use it when you need pre-built, customizable components that enhance user experience with smooth animations and interactions.

## When to use this skill

Apply this skill when the user asks to:
- "Create an animated button"
- "Build a loading indicator"
- "Make an animated card"
- "Create a modal/dialog"
- "Build an animated navbar"
- "Make a dropdown menu"
- "Create an animated form"
- "Build a toast notification"
- "Make an animated toggle"
- "Create an animated accordion"
- "Build a carousel/slider"
- "Make animated tabs"

## What this skill does

1. **Creates reusable components** - standalone, copy-paste ready
2. **Supports component types**:
   - Buttons (hover, click, loading states)
   - Cards (flip, expand, reveal animations)
   - Modals/Dialogs (fade in, slide, scale)
   - Navbars (collapse, highlight, scroll effects)
   - Dropdowns (slide, rotate, custom animations)
   - Forms (input focus animations, validation)
   - Notifications/Toasts (slide, fade, bounce)
   - Loaders (spinners, dots, progress)
   - Toggles/Switches (animated state changes)
   - Accordions (smooth expand/collapse)
   - Carousels/Sliders (smooth transitions)
   - Tabs (animated content switching)
3. **Handles interactions** - hover, click, focus, scroll
4. **Provides customization** - colors, sizes, timing
5. **Includes accessibility** - keyboard navigation, ARIA labels
6. **Ensures performance** - optimized animations

## Output format

Components are created as:
- **Self-contained HTML** with embedded CSS/JS
- **Copy-paste ready** - just drop in your project
- **Customizable** - easy to modify colors, sizes, timing
- **Accessible** - keyboard support, ARIA labels
- **Responsive** - adapts to screen sizes

## Best practices

- Keep components focused and single-purpose
- Use semantic HTML for accessibility
- Provide keyboard navigation
- Respect prefers-reduced-motion
- Optimize animations for performance
- Test on various devices and browsers
- Provide clear documentation
- Make components theme-able
- Use consistent naming conventions
- Keep dependencies minimal
