# Animated Charts Skill

This skill creates engaging, animated data visualizations with smooth transitions, dynamic updates, and motion effects. Use it when you want charts that tell a story through animation.

## When to use this skill

Apply this skill when the user asks to:
- "Create an animated chart"
- "Make a chart that animates data"
- "Build a chart with smooth transitions"
- "Animate data changes"
- "Create a time-series animation"
- "Make a chart that reveals data gradually"
- "Build an animated dashboard"
- "Show data changes with animation"
- "Create an animated infographic"

## What this skill does

1. **Creates animated visualizations** - smooth transitions between data states
2. **Supports animation types**:
   - Data entry animations (bars growing, lines drawing)
   - Transition animations (morphing between chart types)
   - Update animations (smooth data changes)
   - Reveal animations (progressive data display)
   - Scroll animations (triggered by scrolling)
3. **Handles real-time updates** - charts update smoothly with new data
4. **Provides timing control** - duration, delay, easing functions
5. **Includes playback controls** - play, pause, replay animations
6. **Supports interactive animations** - triggered by user actions
7. **Enables storytelling** - animate data to highlight insights

## Animation Features

### Entry Animations
- Bars expanding from baseline
- Lines drawing across chart
- Pie slices rotating into place
- Data points fading in
- Progressive label reveals

### Transition Animations
- Morphing between chart types
- Smooth axis transformations
- Layout reflow animations
- Staggered element animations
- Sequential data reveals

### Update Animations
- Smooth value changes
- Color transitions
- Size morphing
- Position updates
- Staggered updates

### Interactive Animations
- Hover highlight animations
- Click drill-down animations
- Filter transitions
- Sort animations
- Zoom/pan effects

## Chart Types That Animate

- Bar Charts - bars expanding/collapsing
- Line Charts - lines drawing dynamically
- Pie Charts - slices rotating and scaling
- Area Charts - areas filling progressively
- Scatter Plots - points appearing with trail effects
- Bubble Charts - bubbles expanding and repositioning
- Heatmaps - color transitions and intensity changes
- Tree Maps - hierarchical reveals and reflows

## How to use this skill

When invoked, this skill will:
1. Understand the data and story
2. Design an animation sequence
3. Choose appropriate easing and timing
4. Generate animated visualization with controls
5. Include play/pause functionality
6. Add replay capability

## Output format

Animated charts are created as:
- **Interactive HTML/SVG/Canvas** visualizations
- **Smooth 60fps animations** using requestAnimationFrame
- **GPU-accelerated** CSS transforms
- **Customizable timing** - duration, delay, easing
- **Playback controls** - play, pause, speed control
- **Responsive animations** - adapt to screen size
- **Mobile-optimized** performance

## Animation Timing

### Fast (500ms)
- Quick data updates
- Dashboard refreshes
- Simple transitions

### Medium (1000-1500ms)
- Default animations
- Story-driven reveals
- Smooth transitions

### Slow (2000ms+)
- Dramatic reveals
- Educational content
- Emphasis animations

## Easing Functions

- Linear - constant speed
- Ease-in - slow start, fast end
- Ease-out - fast start, slow end
- Ease-in-out - slow start and end
- Cubic-bezier - custom curves
- Elastic - bouncy effect
- Back - overshoot effect

## Best practices

- Use animation to emphasize key insights
- Keep animations smooth and performant
- Respect user's motion preferences
- Provide pause/skip options
- Test on various devices
- Avoid excessive animations (distraction)
- Match animation style to content tone
- Use consistent timing across sequences
