# Frontend Slides Skill

This skill creates beautiful, interactive presentation slides using modern web technologies. Use it when you need to generate slide decks for presentations, educational content, or visual storytelling.

## When to use this skill

Apply this skill when the user asks to:
- "Make slides" or "create slides"
- "Generate a presentation"
- "Build a slide deck"
- "Make a slideshow"
- Create presentation content on any topic

## What this skill does

1. **Creates interactive slide presentations** - generates HTML/CSS-based slides with smooth transitions
2. **Supports multiple slide layouts** - title slides, content slides, image slides, code slides, etc.
3. **Provides styling options** - light/dark themes, custom colors, typography
4. **Enables slide navigation** - keyboard and button controls for navigation
5. **Handles various content types** - text, images, code snippets, charts, lists, quotes

## How to use this skill

When invoked, this skill will:
1. Ask about the slide topic/content if not provided
2. Request the number of slides or outline
3. Determine the presentation style/theme
4. Generate an interactive slide deck as an HTML artifact
5. Allow for visual tweaking and customization

## Output format

Slides are created as:
- **Interactive HTML artifacts** with navigation controls
- **Responsive design** that works on different screen sizes
- **Keyboard shortcuts** (Arrow keys: left/right to navigate, Home/End for first/last, etc.)
- **Mouse/touch support** for slide navigation
- **Print-friendly** option for PDF export

## Best practices

- Keep text concise - slides work best with bullet points, not paragraphs
- Use visuals to enhance content
- Maintain consistent styling across slides
- Consider audience when choosing themes/colors
- Test navigation on different devices

## Examples

When user says: "Make slides about climate change with 5 slides"
→ Creates a presentation on climate change with 5 well-structured slides

When user says: "Generate a product pitch deck"
→ Creates a professional pitch deck with standard sections (Problem, Solution, Market, etc.)

When user says: "Make slides for Python tutorial"
→ Creates educational slides with code examples, explanations, and visual demonstrations
