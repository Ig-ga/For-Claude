# Animation Skill

This skill creates smooth, engaging animations and motion graphics using modern web technologies. Use it when you need to generate animated visual content, interactive effects, or motion-based designs.

## When to use this skill

Apply this skill when the user asks to:
- "Create an animation"
- "Make an animated [something]"
- "Build a loading animation"
- "Generate a motion graphic"
- "Animate [element/concept]"
- "Create a bouncing/sliding/fading effect"
- "Design animated transitions"
- "Build a particle effect"
- "Make an interactive animation"

## What this skill does

1. **Creates smooth animations** - CSS animations, JavaScript transitions, and canvas-based animations
2. **Supports multiple animation types** - bouncing, fading, sliding, rotating, scaling, morphing, particle effects
3. **Provides interactive elements** - animations triggered by user actions, hover effects, click interactions
4. **Handles transitions** - smooth transitions between states, page transitions, element transformations
5. **Supports various effects** - loading spinners, progress bars, floating elements, wave effects, 3D transforms
6. **Creates motion graphics** - animated text, animated icons, data visualizations with motion, visual storytelling

## Animation Categories

### Load & Progress

### Interactive Effects

- Click-triggered animations

### Text Animations

## How to use this skill

When invoked, this skill will:
1. Clarify what you want to animate
2. Determine the animation style/type
3. Define triggers (auto-play, hover, click, scroll)
4. Generate an interactive HTML artifact with the animation
5. Include customization options (speed, colors, size, effects)

## Output format

Animations are created as:
- **Interactive HTML/CSS/JavaScript** artifacts
- **Performant** using CSS transforms and GPU acceleration
- **Responsive** that adapts to screen sizes
- **Customizable** - colors, speed, timing, size
- **Cross-browser compatible**
- **Touch-friendly** for mobile devices

## Best practices

- Use animations to enhance UX, not distract
- Consider performance for complex animations
- Test on different devices
- Provide accessibility (respect prefers-reduced-motion)
- Match animation speed to content
- Use purposeful easing functions (ease-in, ease-out, cubic-bezier)
