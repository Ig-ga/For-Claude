# Data Charts Skill

This skill creates beautiful, interactive data visualizations and charts. Use it when you need to display data in visual formats that are easy to understand and analyze.

## When to use this skill

Apply this skill when the user asks to:
- "Create a chart of [data]"
- "Make a graph showing [metrics]"
- "Visualize [data type]"
- "Build a dashboard with charts"
- "Plot [data]"
- "Generate a bar/pie/line chart"
- "Create data visualization"
- "Show statistics visually"
- "Build analytics dashboard"

## What this skill does

1. **Creates interactive charts** - multiple chart types for different data presentations
2. **Supports all major chart types**:
   - Bar charts (horizontal/vertical)
   - Line charts (single/multi-line)
   - Pie/Donut charts
   - Area charts
   - Scatter plots
   - Bubble charts
   - Heatmaps
   - Sankey diagrams
   - Tree maps
   - Histograms
3. **Handles data processing** - aggregation, filtering, sorting
4. **Provides interactivity** - hovering, clicking, filtering data
5. **Includes customization** - colors, legends, tooltips, axis labels
6. **Supports responsive design** - adapts to different screen sizes
7. **Allows data updates** - charts can be updated with new data

## Chart Types & Use Cases

### Basic Charts
- **Bar Charts** - comparing categories, performance metrics
- **Line Charts** - trends over time, multiple series
- **Pie Charts** - showing proportions and percentages
- **Area Charts** - cumulative trends, stacked areas

### Advanced Charts
- **Scatter Plots** - correlations, distributions
- **Bubble Charts** - 3-variable comparisons
- **Heatmaps** - density visualization, patterns
- **Box Plots** - statistical distribution
- **Histograms** - frequency distributions

### Complex Visualizations
- **Sankey Diagrams** - flow and relationships
- **Tree Maps** - hierarchical data
- **Sunburst Charts** - multi-level categories
- **Network Graphs** - connections and relationships

## How to use this skill

When invoked, this skill will:
1. Analyze the data you provide
2. Recommend the best chart type
3. Process and prepare the data
4. Generate an interactive visualization
5. Add interactivity (tooltips, legends, filters)
6. Make it responsive and accessible

## Output format

Charts are created as:
- **Interactive HTML/SVG visualizations**
- **Using D3.js, Recharts, or Chart.js**
- **Responsive** for all screen sizes
- **Accessible** with ARIA labels and keyboard navigation
- **Themeable** with light/dark mode support
- **Exportable** as PNG/SVG when needed

## Features

- **Data Input** - arrays, CSV, JSON formats
- **Color Schemes** - sequential, diverging, categorical palettes
- **Legend Control** - automatic or custom legends
- **Tooltip Customization** - formatted data display on hover
- **Axis Configuration** - labels, scales, ranges
- **Grid Lines** - reference lines for easier reading
- **Animations** - smooth transitions and data updates
- **Click Handlers** - interactive drill-down capabilities
- **Export Options** - save as image or data

## Best practices

- Choose chart type based on data and story
- Avoid chart junk - keep it clean and focused
- Use color purposefully (not decoratively)
- Label everything clearly (axes, series, units)
- Include data source attribution
- Make numbers legible (avoid overcrowding)
- Use consistent color schemes across dashboards
- Consider accessibility (colorblind-friendly palettes)
